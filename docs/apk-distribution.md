# Android 測試版下載與發佈

實機測試指南：[台灣正體中文](testing-zh-TW.md) · [English](testing-en.md) · [日本語](testing-ja.md)。Release 預設使用台灣正體中文，並附上 `TESTING.md`、`TESTING.en.md`、`TESTING.ja.md`。以下為維護者的發佈說明。

The `Publish Android PoC` GitHub Actions workflow builds and tests the tagged source, then publishes **the same application APK** to a GitHub prerelease and GitHub Packages (Maven). It also uploads the instrumentation APK, three complete testing guides and SHA-256 checksums to the Release and a 30-day Actions artifact. Release assets and Packages do not use that artifact expiration.

## Publish

The integrator reviews the exact commit, pushes an immutable tag such as `android-poc-v0.0.1-poc.20261011.1`, and verifies the resulting Actions run, Release assets and package version. This is an explicit test-build publication, not a production deployment. Tags use `android-poc-v<major>.<minor>.<patch>-poc.<YYYYMMDD>.<sequence>`; increment the sequence for each build. Do not move or reuse a published tag/version.

Only tag pushes can publish; pull requests cannot. The publication job uses the repository's short-lived `GITHUB_TOKEN` with `contents: write` and `packages: write`. No personal token or signing secret is stored in the repository. Maven settings are generated by `setup-java`; the registry owner is lowercased as required by GitHub Packages.

If publication partially fails, inspect both the exact Release and package version before retrying. A package may already exist even if the Release step failed. Preserve successful output and publish a new version for rebuilt APKs; do not overwrite assets or assume a wrapper failure means nothing was published.

## Download and test

Use the complete guide in your preferred language: [台灣正體中文](testing-zh-TW.md), [English](testing-en.md), or [日本語](testing-ja.md). The same guides are attached to each Release as `TESTING.md`, `TESTING.en.md`, and `TESTING.ja.md`; the default Release description is Taiwan Traditional Chinese.

The app defaults to zh-TW on first launch and stores the selected language. Switching language does not rewrite existing files or document IDs. The guides include installation/signing limitations, system-picker discovery, app-specific storage, BOOK☆WALKER checks, optional instrumentation and a report template.

## Packages

The repository's **Packages** section lists `tw.suizai.suizai-android-poc`. Maven coordinate: `tw.suizai:suizai-android-poc:<version>` with type `apk`, registry `https://maven.pkg.github.com/konohaderek/suizai`. This is APK distribution through Maven, not an Android library dependency.

For manual installation, Release assets are the simplest download path. Automated Maven clients need package-read authentication; GitHub documents [Maven registry access](https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-apache-maven-registry). Never paste tokens into issues or build reports.
