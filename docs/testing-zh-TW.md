# SUIZAI Android 實機測試指南

## 安裝與語言

1. 登入具有此私人儲存庫存取權的 GitHub 帳號，在 Release 下載 `suizai-<版本>.apk`、`SHA256SUMS` 與本指南。一般手動測試不需要安裝 `androidTest.apk`。
2. 以 `shasum -a 256 suizai-<版本>.apk` 核對 `SHA256SUMS`。Release 與 Packages 提供的是同一個 App APK。
3. 在 Android 8.0 以上測試裝置安裝 APK；依系統提示允許這次安裝來源。每次 CI 使用不同的測試簽章，更新舊版可能需要先解除安裝，這會刪除 App 的本機資料與測試檔。先保存需要的測試紀錄。
4. 開啟 App，首次啟動應顯示**台灣正體中文**。在「語言」切換 **English** 或 **日本語**，關閉再開啟 App，確認選擇有保留。這不會更改手機或 BOOK☆WALKER 的語言。
5. 切換語言不會改寫既有檔案或更換文件 ID。新建立的測試檔使用建立當時的 App 語言；舊檔保留原文。

## 系統檔案選擇器（issue #1）

1. 點選「**開啟系統檔案選擇器**」，再點左上角選單，展開**儲存位置清單**。「最近使用」畫面本身不會列出所有儲存來源。
2. 在清單選取 **SUIZAI 隨載**，確認可看見並讀取 `Books/README.txt`。
3. 使用支援系統檔案選擇器的文字編輯器，在 SUIZAI 建立可丟棄的文字檔，寫入、關閉、重新開啟、重新命名，再刪除。
4. 重新啟動手機，確認 SUIZAI 與保留的測試檔仍可存取。
5. 若展開清單後仍找不到 SUIZAI，記錄「系統選擇器未列出」，附上選擇器的完整清單與裝置資訊。不要把 App 的自我檢查當作這項測試成功。

較早的 PoC 使用路徑式文件 ID；舊版取得的檔案授權不會轉移到 UUID 版本，請從系統選擇器重新選取。

## App 專用儲存空間（issue #3）

1. 點選「**建立測試資料夾**」。每個可寫入的 App 專用儲存位置都會建立新的 `suizai-external-probe/run-…` 資料夾，內含 `SUIZAI-test.txt`。
2. 畫面會顯示儲存狀態、App 儲存路徑、測試資料夾及自我檢查結果。長按文字可複製路徑。
3. 自我檢查會建立、寫入、重新命名、重新讀取及刪除 App 自己的暫存檔。通過只代表 SUIZAI 能操作自己的資料夾，**不代表 BOOK☆WALKER 有存取權**。
4. 分別切換三種語言並建立新資料夾，確認新 `SUIZAI-test.txt` 的內容與當時語言相符；先前的資料夾與檔案應保留原樣。完成紀錄後再自行清除不需要的測試資料。

## BOOK☆WALKER 相容性（issues #2、#3）

1. 使用專用測試帳號、裝置及可丟棄內容，查看 BOOK☆WALKER 的儲存設定，記錄列出的名稱與路徑。
2. 記錄畫面只提供儲存根目錄，或也能選擇子資料夾／開啟系統選擇器。既有 SD 卡根目錄不是 SUIZAI 新增的虛擬磁碟。
3. 若畫面提供選擇測試資料夾或操作文字檔的功能，才測試讀取 `SUIZAI-test.txt`，並對另一個可丟棄文字檔進行建立、寫入、重新開啟、重新命名及刪除。
4. 若無法選取或沒有這項功能，記錄「未列出／無此操作」及實際畫面即可。不要為測試搬移既有下載書籍或複製 DRM 內容。

## 回報格式

在 [#1](https://github.com/KonohaDerek/suizai/issues/1) 回報系統選擇器結果；在 [#3](https://github.com/KonohaDerek/suizai/issues/3) 回報 App 專用目錄／BOOK☆WALKER 結果。

| 項目 | 請填寫 |
|---|---|
| 裝置 | 廠牌、型號、Android 版本、系統版本號碼 |
| 軟體 | 本次 Release 版本、APK SHA-256、BOOK☆WALKER／文字編輯器版本 |
| 語言 | 台灣正體中文／English／日本語；重開 App 後是否保留 |
| 系統選擇器 | 左側清單是否列出 SUIZAI；各檔案操作與重開機結果 |
| 儲存目錄 | 路徑、儲存狀態、自我檢查結果 |
| BOOK☆WALKER | 是否列出／可選取測試位置；實際提供的操作與結果 |
| 證據 | 步驟、錯誤訊息、已遮蔽電話及網路識別資訊的截圖 |

這是以本機模擬檔案驗證相容性的測試版。遠端儲存、OAuth、快取加密、root 掛載及中斷上傳復原尚未實作；CI 通過不等於實機或 BOOK☆WALKER 相容性通過。

如要自行執行自動化裝置測試，可另安裝同一 Release 的 `androidTest.apk`，再執行 `adb shell am instrument -w tw.suizai.app.test/androidx.test.runner.AndroidJUnitRunner`。一般手動驗證可略過此步驟。
