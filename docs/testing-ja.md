# SUIZAI Android 実機テストガイド

## インストールと言語

1. この非公開リポジトリにアクセスできる GitHub アカウントでログインし、Release から `suizai-<バージョン>.apk`、`SHA256SUMS`、本ガイドをダウンロードします。手動テストでは `androidTest.apk` のインストールは不要です。
2. `shasum -a 256 suizai-<バージョン>.apk` の結果を `SHA256SUMS` と照合します。Release と Packages のアプリ APK は同一です。
3. Android 8.0 以降のテスト端末にインストールし、表示された案内に従ってインストール元を許可します。CI ビルドごとにデバッグ署名鍵が異なるため、旧版を先にアンインストールする必要がある場合があります。その際、アプリ内のローカルデータとテストファイルは削除されます。必要な記録を先に保存してください。
4. アプリの初回起動時は **台灣正體中文**（台湾繁体字中国語）で表示されます。「**語言 / 言語**」で **English** または **日本語**に切り替え、アプリを閉じて再度開き、選択が保持されることを確認します。端末や BOOK☆WALKER の言語は変更されません。
5. 言語の切り替えでは既存ファイルやドキュメント ID は変更されません。新しいテストファイルには作成時のアプリ言語が使われ、既存ファイルの内容はそのまま残ります。

## システムのファイル選択画面（issue #1）

1. 「**システムのファイル選択画面を開く**」をタップし、左上のメニューから**保存場所の一覧**を開きます。「最近使った項目」だけではすべての保存場所は表示されません。
2. **SUIZAI 隨載**を選択し、`Books/README.txt` が表示され、読み取れることを確認します。
3. システムのファイル選択画面に対応したテキストエディターで、SUIZAI 内に破棄可能なテキストファイルを作成し、書き込み、閉じる、再度開く、名前変更、削除を試します。
4. 端末を再起動し、SUIZAI と保存したテストファイルに引き続きアクセスできることを確認します。
5. 保存場所の一覧を開いても SUIZAI がない場合は、「システムの一覧に表示されない」と記録し、一覧全体と端末情報を添えてください。アプリ内の自己チェックだけでは、この確認に合格したことにはなりません。

旧 PoC はパス形式のドキュメント ID を使用していました。保存済みのファイルアクセス権は UUID 版には移行されないため、システムの選択画面からファイルを選び直してください。

## アプリ専用ストレージ（issue #3）

1. 「**テストフォルダーを作成**」をタップします。書き込み可能な各アプリ専用保存場所に、新しい `suizai-external-probe/run-…` フォルダーと `SUIZAI-test.txt` が作成されます。
2. 画面にはストレージの状態、アプリの保存先、テストフォルダーのパス、自己チェックの結果が表示されます。文字列を長押しするとパスをコピーできます。
3. 自己チェックでは、アプリ自身の一時ファイルを作成、書き込み、名前変更、再読み込み、削除します。成功は SUIZAI が自身のフォルダーを操作できることを示すだけで、**BOOK☆WALKER のアクセス権を確認するものではありません**。
4. 3 つの言語をそれぞれ選んで新しいフォルダーを作り、新しい `SUIZAI-test.txt` の内容が作成時の言語と一致することを確認します。以前のフォルダーとファイルは変更されないことも確認してください。不要なテストデータは結果を記録してから手動で削除します。

## BOOK☆WALKER の互換性（issues #2、#3）

1. 専用のテストアカウント・端末と破棄可能なデータを使用し、BOOK☆WALKER の保存先設定に表示される名前とパスを記録します。
2. ストレージのルートだけを選べるのか、サブフォルダーの選択やシステムのファイル選択画面も利用できるのかを記録します。既存の SD カードのルートは、SUIZAI が追加した仮想ディスクではありません。
3. テストフォルダーの選択やテキストファイルの操作が提供されている場合に限り、`SUIZAI-test.txt` の読み取りと、別の破棄可能なテキストファイルの作成、書き込み、再読み込み、名前変更、削除を試します。
4. 保存先や操作が提供されていない場合は、「表示されない／操作できない」と画面の状態を記録してください。このテストのために既存のダウンロード済み書籍を移動したり、DRM コンテンツをコピーしたりしないでください。

## 結果の報告

システムのファイル選択画面の結果は [#1](https://github.com/KonohaDerek/suizai/issues/1)、アプリ専用フォルダーと BOOK☆WALKER の結果は [#3](https://github.com/KonohaDerek/suizai/issues/3) に記録します。

| 項目 | 記録する内容 |
|---|---|
| 端末 | メーカー、型番、Android バージョン、システムのビルド番号 |
| ソフトウェア | Release バージョン、APK SHA-256、BOOK☆WALKER／エディターのバージョン |
| 言語 | 台灣正體中文／English／日本語、アプリ再起動後の保持状態 |
| システムの選択画面 | 一覧に SUIZAI があるか、各ファイル操作と端末再起動の結果 |
| 保存先 | パス、ストレージの状態、自己チェックの結果 |
| BOOK☆WALKER | テスト保存先の表示・選択の可否、利用できた操作と結果 |
| 証拠 | 手順、エラー、電話番号やネットワーク識別情報を隠したスクリーンショット |

本テスト版はローカルの模擬ファイルで互換性を確認します。リモートストレージ、OAuth、キャッシュ暗号化、root マウント、中断したアップロードの復旧は未実装です。CI の成功だけでは実機や BOOK☆WALKER との互換性は確認できません。

自動化された端末テストを実行する場合は、同じ Release の `androidTest.apk` もインストールし、`adb shell am instrument -w tw.suizai.app.test/androidx.test.runner.AndroidJUnitRunner` を実行します。手動テストでは省略できます。
